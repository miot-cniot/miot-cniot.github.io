    Actividad 1

    MENSAJERÍA MQTT A TRAVÉS DE LOS ARCHIVOS DE PUBLICACIÓN Y SUSCRIPCIÓN.

    Objetivo

    El objetivo de esta actividad es comprobar el funcionamiento de la mensajería MQTT del Device Client a través de los archivos de publicación y suscripción.

    Nota

    Puedes ver aquí la documentación.

    Comprobación del funcionamiento de la mensajería MQTT

    Haz lo siguiente:

    1. Comprueba en un terminal de la instancia VSCode deviceClient en la que está instalado el AWS IoT Device Client la configuración actual de la mensajería MQTT.

      $ sudo cat /etc/.aws-iot-device-client/aws-iot-device-client.conf | jq '.samples'
{
  "pub-sub": {
    "enabled": true,
    "publish-topic": "/topic/workshop/dc/pub",
    "publish-file": "/etc/.aws-iot-device-client/pubsub/publish-file.txt",
    "subscribe-topic": "/topic/workshop/dc/sub",
    "subscribe-file": "/home/ubuntu/workshop_dc/subfile.txt"
  }
}

      La salida muestra que la funcionalidad está activada y los temas MQTT y archivos locales que se están utilizando para el intercambio de mensajes.

    2. Comprueba el contenido del archivo de suscripción.

      $ cat /home/ubuntu/workshop_dc/subfile.txt
{
  "message": "Saudações do console do AWS IoT"
}

    3. En el cliente MQTT de la consola de AWS IoT publica un mensaje en el tema /topic/workshop/dc/sub.

      Nota

      Para poder ver el mensaje publicado tienes que suscribirte primero al tema.

      Mensaje publicado en el tema MQTT.

    4. Comprueba en la instancia VSCode que se actualizó el archivo de suscripción.

      $ cat /home/ubuntu/workshop_dc/subfile.txt
{
  "message": "Saudações do console do AWS IoT"
}
{
  "message": "Adeus rios, adeus fontes"
}

    5. Comprueba también el archivo de log.

      $ sudo grep Message /var/log/aws-iot-device-client/aws-iot-device-client.log
2024-08-02T10:07:22.562Z [DEBUG] {samples/PubSubFeature.cpp}: Message received on subscribe topic, size: 44 bytes

    6. Comprueba ahora el contenido del archivo de publicación.

      $ sudo cat /etc/.aws-iot-device-client/pubsub/publish-file.txt                                                                                             
{"Hello": "World!"}
      Como ya vimos en el curso en línea, este es el mensaje que se envía al tema de publicación configurado cada vez que se reinicia el servicio aws-iot-device-client. Editar el contenido de ese archivo y reiniciar el servicio es el procedimiento por defecto para publicar un mensaje.

    Publicando mensajes MQTT cuando el archivo cambia

    Otra manera de publicar mensajes MQTT en el Device Client es hacerlo cada vez que hay un cambio en el archivo de publicación, sin necesidad de reiniciar el servicio.

    Para comprobar este método de publicación haz lo siguiente:

    1. Edita el archivo de configuración del Device Client añadiendo el campo publish-on-change con el valor true al objeto pub-sub para activar la publicación de mensajes cuando haya cambios en el archivo. Edita también en el campo publish-file el archivo que se va a usar para publicar.

      Nota

      Para editar el archivo puedes usar, p.ej., el editor nano.

      $ sudo nano /etc/.aws-iot-device-client/aws-iot-device-client.conf 

      $ sudo cat /etc/.aws-iot-device-client/aws-iot-device-client.conf | jq '.samples'
{
  "pub-sub": {
    "enabled": true,
    "publish-topic": "/topic/workshop/dc/pub",
    "publish-file": "/home/ubuntu/workshop_dc/pubfile.txt",
    "subscribe-topic": "/topic/workshop/dc/sub",
    "subscribe-file": "/home/ubuntu/workshop_dc/subfile.txt",
    "publish-on-change": true
  }
}

    2. Crea el archivo de publicación.

      $ cd /home/ubuntu/workshop_dc
$ touch pubfile.txt 
$ chmod 600 pubfile.txt
$ echo '{"message":"Saúdos desde o Device Client"}' > pubfile.txt
$ cat pubfile.txt
{"message":"Saúdos desde o Device Client"}

    3. En el cliente MQTT de la consola de AWS IoT subscríbete al tema /topic/workshop/dc/pub.

    4. Reinicia el servicio y comprueba que no haya habido ningún error.

      $ sudo systemctl restart aws-iot-device-client
$ sudo systemctl status aws-iot-device-client

      Estado del servicio Device Client.

    5. Comprueba en el cliente MQTT que se recibió en el tema /topic/workshop/dc/pub el mensaje guardado en el archivo pubfile.txt en el paso 2.

      Mensaje recibido en el tema MQTT.

    6. Publica otro mensaje usando el archivo y comprueba que también aparece en el cliente MQTT.

      $ echo '{"message":"Adeus rios, adeus fontes"}' > pubfile.txt

    7. Comprueba también el archivo de log.

      $ sudo grep "target file" /var/log/aws-iot-device-client/aws-iot-device-client.log -A 1 
2024-08-02T11:38:34.975Z [DEBUG] {samples/PubSubFeature.cpp}: The target file is modified, start updating the shadow
2024-08-02T11:38:34.982Z [DEBUG] {samples/PubSubFeature.cpp}: PublishCompAck: PacketId:(Pub Sub Sample), ErrorCode:0

    Justificación de la actividad

    Toma las siguientes capturas para la memoria de justificación de la práctica:

    1. Instancia VSCode deviceClient mostrando la salida de la ejecución de los comandos siguientes: 
      $ sudo cat /etc/.aws-iot-device-client/aws-iot-device-client.conf | jq '.samples'
$ echo '{"message":"Saúdos de <PON_AQUI_TU_NOMBRE> desde o Device Client"}' > /home/ubuntu/workshop_dc/pubfile.txt
    2. Cliente MQTT en la consola del AWS IoT con el mensaje recibido en el tema /topic/workshop/dc/pub, en la que pueda verse el payload, después de ejecutar los comandos del punto anterior.

    Importante

    Las capturas tienen que parecerse a las que se tomaron en el curso y en las prácticas anteriores. Las capturas tomadas en la consola AWS tienen que incluir el menú superior en el que pueda verse el nombre de usuario de la cuenta.
