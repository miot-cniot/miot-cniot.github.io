    5. Conexión de un dispositivo: visión general del proceso

    La consola de AWS IoT Core proporciona dos opciones para conectar dispositivos: conectar un solo dispositivo o conectar varios al mismo tiempo.

    A continuación, se presenta una visión general paso a paso del proceso para aprovisionar un solo dispositivo, tal como se describe en el escenario. En este ejemplo, usaremos el SDK de Python de AWS, pero se podría usar cualquier cliente MQTT moderno para conectarse a AWS IoT Core.

    Conexión de un dispositivo

    Esta visión general tiene dos partes. En la primera parte, comenzaremos lanzando una instancia VSCode que sirva de emulación de un dispositivo para nuestro ejemplo. En la segunda parte, crearemos un objeto de AWS IoT, añadiremos atributos y descargaremos el kit de conexión para el dispositivo.

    Parte 1: Preparación de la instancia VSCode

    Para lanzar la instancia VSCode que sirva de emulación de un dispositivo en nuestro ejemplo, haz lo siguiente:

    1. Accede a la consola de AWS desde el AWS Academy Learner Lab.

    2. Lanza una instancia VSCode siguiendo las instrucciones del documento que tienes disponible en Moovi. Usa el nombre TruckSensor y recuerda añadirle tu prefijo.

    3. Abre una terminal en la instancia que acabas de lanzar y ejecuta lo siguiente para descargar y descomprimir el archivo con lo necesario para emular el dispositivo:

      wget https://miot-cniot.github.io/stuff/TruckSensorFiles.zip && unzip TruckSensorFiles.zip

      Contenidos del archivo

      Los contenidos del archivo comprimido descargado son los siguientes:

      • Una carpeta de certificados que contiene el certificado público de la autoridad de certificación raíz de AWS, que es necesaria para conectarse a AWS IoT Core
      • Una carpeta de datos con un archivo .csv usado para emular las medidas del sensor del camión
      • Una carpeta de scripts que contiene el script utilizado para simular el sensor del camión

    4. Mueve las tres nuevas carpetas (certs, data, scripts) en TruckSensorFiles al directorio /home/ubuntu. Una vez movidas puedes eliminar tanto el directorio TruckSensorFiles como el fichero TruckSensorFiles.zip.

      Carpetas (certs, data y scripts) en la instancia de VSCode una vez movidas.

    Parte 2: Crear un objeto

    En la segunda parte de esta visión general del proceso de conexión de un dipositivo, vamos a:

    • Crear un tipo de objeto y añadirle atributos.

    • Crear el objeto que representa el sensor (lo que está siendo emulado por la instancia de VSCode que acabamos de lanzar en la parte 1).

    Haz lo siguiente para completar esta parte:

    1. Crear un tipo de objeto

    Comencemos creando un tipo de objeto. De esta manera, al crear un objeto, podrás asociarla con el tipo de objeto.

    1. En el menú de la izquierda, selecciona la opción: Administrar -> Todos los dispositivos -> Tipos de objetos.

    2. Elige Crear tipo de objeto para empezar a definir un tipo que represente al sensor del camión.

    1. Introduce el nombre sensor_TempAndDoor. Recuerda añadir tu prefijo delante.

      Añadir una descripción es opcional pero útil, ya que proporciona más detalles sobre la información que captura el sensor.

    1. En la sección Configuración adicional, debajo de las propiedades del tipo de objeto, expande Atributos que se pueden buscar.

    2. Haz clic en Agregar atributo tres veces y añade los siguientes tres atributos: deviceID, powerRequired y trailerCapacity. Cada sensor, registrado como objeto, podrá establecer valores individuales para estos atributos.

      Propiedades del tipo de objeto.

    3. Haz clic en Crear tipo de objeto para crear el tipo de objeto.

    2. Crear el objeto que representa al sensor

    1. En el menú de la izquierda en la consola del servicio AWS IoT Core, selecciona la opción: Conectarse -> Conectar un dispositivo.

      Se muestra la página del asistente Conectar un dispositivo, que ayuda a crear los recursos del objeto, la política de IoT y los recursos del certificado necesarios para conectar el dispositivo a AWS IoT y que pueda publicar mensajes de ejemplo.

      El asistente sigue los siguientes cinco pasos en el proceso:

      1. Prepara el dispositivo.

      2. Registra y protege el dispositivo.

      3. Elige una plataforma y un SDK.

      4. Descarga el kit de conexión.

      5. Ejecuta el kit de conexión.

    2. Como el paso 1: Preparar el dispositivo, ya se hizo al preparar la instancia VSCode en la parte 1, haz click en el botón Siguiente para avanzar al segundo paso del asistente: Registrar y proteger su dispositivo.

    3. En la página Registrar y proteger tu dispositivo, nombra el objeto como truckSensor01. Recuerda añadir tu prefijo delante.

    4. En Configuraciones adicionales expande Tipo de objeto.

    5. En la lista desplegable Tipo de objeto, elige el tipo de objeto que acabamos de crear (sensor_TempAndDoor). Esto poblará automáticamente los atributos del tipo.

      Se podrían añadir valores para el ID del dispositivo, el requisito de energía y la capacidad del remolque ahora o puede hacerse en cualquier otro momento. Déjalos sin valor de momento.

      Propiedades del objeto.

    6. Haz clic en Siguiente para avanzar al siguiente paso del asistente.

    7. El asistente te ayuda a descargar un IoT Device SDK en tu dispositivo. El SDK incluye un programa de ejemplo que publica y se suscribe a mensajes MQTT. Selecciona la plataforma (Linux) y el IoT Device SDK (Python) que coincidan con los de la instancia VSCode que se lanzó en la etapa 1.

      Selección de la plataforma y SDK.

    8. Haz clic en Siguiente para avanzar al siguiente paso del asistente.

    En la etapa de preparación, descargaste un archivo comprimido llamado TruckSensorFiles.zip, que contiene un certificado raíz y un conjunto de datos para simular lecturas de sensores. Ahora vas a descargar el kit de conexión, que es otro archivo comprimido llamado connect_device_package.zip que contienelo necesario para la seguridad del dispositivo: el certificado del dispositivo, la clave pública y la clave privada, además de un script para probar la conectividad con AWS IoT Core.

    1. Haz clic en Descargar kit de conexión para descargar el kit en tu ordenador. De momento no hagas nada con el, lo usaremos más adelante.

    Una vez que descargues el kit de conexión, completa la creación del objeto avanzando por los pasos restantes del asistente.
