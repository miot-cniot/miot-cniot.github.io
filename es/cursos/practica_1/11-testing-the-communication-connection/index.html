    10. Prueba de conexión: visión general del proceso

    Ahora que el dispositivo está registrado y conectado a AWS IoT Core y la política de AWS IoT y los certificados están configurados correctamente para permitir que el sensor publique en un tema especificado, debe probarse la conexión de comunicación para completar la prueba de concepto.

    Cómo suscribirse a un tema MQTT

    En esta sección veremos cómo es el proceso para suscribirse a un tema MQTT y verificar la comunicación con el dispositivo. Haz lo siguiente:

    Ejecutar el cliente en el directorio de scripts

    1. En una terminal de la instancia VSCode, introduce los siguientes comandos para cambiar los permisos y permitir la ejecución del script start.sh en el directorio de scripts:

      $ cd /home/ubuntu/scripts
$ chmod +x start.sh
$ ./start.sh

    2. El script instala el SDK de AWS IoT Device para Python. Cuando acabe te pedirá el nombre de tu objeto. En este caso, introduce truckSensor01 con tu prefijo delante.

    El script se conectará a AWS IoT Core y comenzará a publicar mensajes en el tema truck/freezer. Los mensajes contienen la tensión, la temperatura, el estado de la puerta abierta o cerrada y una marca de tiempo.

    Ejecutando el script en la terminal.

    Confirmar la comunicación con AWS IoT Core

    1. En el menú izquierdo de la consola de AWS IoT Core, selecciona la opción: Probar -> Cliente de prueba de MQTT.

    2. Introduce el nombre del tema truck/freezer en el filtro de temas y haz clic en el botón Suscribir para mostrar los mensajes.

      Suscripción a un tema.

      Si aparecen mensajes en el tema, eso indica que la comunicación entre el dispositivo y AWS IoT Core está funcionando. Los datos de cada mensaje indican cuánto tiempo lleva funcionando el dispositivo, la temperatura en la parte trasera del camión, la energía que va a la unidad de congelación y una marca de tiempo en formato epoch.

    Note

    Una vez comprobado que la conexión con AWS IoT funciona, puede interrumpirse la ejecución del script start.sh en la terminal de la instancia VSCode pulsando Ctrl+C.
