    5. Prueba de conexión

    Comprobación de la configuración

    En este punto del curso vamos a verificar que disponemos de una instancia VSCode y su cosa asociada correctamente configuradas para poder establecer una conexión entre el dispositivo (la instancia VSCode) y el AWS IoT Core usando MQTT desde un cliente implementado mediante el SDK de Python de AWS.

    IMPORTANTE

    Esta sección asume que tanto la instancia VSCode como su cosa asociada ya se crearon y configuraron en la práctica 1. Aquí solo se verifica que se pueda establecer conexión entre la instancia y el AWS IoT Core.

    Si no tienes creadas la instancia y su cosa asociada, antes de continuar haz primero la práctica 1.

    Configuración de la instancia VSCode

    Para verificar la configuración de la instancia VSCode haz lo siguiente:

    1. Accede a la consola de gestión de AWS desde el AWS Academy Learner Lab.

    2. Accede a la consola del servicio CloudFormation.

    3. Desde la pestaña Salidas de la pila TruckSensor abre en un navegador la URL del VSCode instalado en la instancia.

    Contraseña

    Si no recuerdas la contraseña de acceso, mira en el documento que explica cómo lanzar instancias VSCode.

    1. Asegúrate de que la instancia contiene los certificados y scripts que se instalaron en la práctica 1.

    Configuración de la política de AWS IoT

    Para revisar la política de AWS IoT asociada a la cosa haz lo siguiente:

    1. Accede a la consola del servicio AWS IoT.

    2. Abre las propiedades de la política truckSensor01-Policy (la que se creó en la práctica 1).

    3. Asegúrate de que la versión activa de la política coincida con la captura y el JSON proporcionados a continuación como ejemplos.

    JSON

    El JSON de la política tiene que coincidir con este ejemplo, sustituyendo los valores de YOUR_REGION con tu código de región de AWS, como us-east-1, y YOUR_ACCOUNT_NUMBER con tu número de cuenta de AWS.

    {
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "iot:Connect"
      ],
      "Resource": [
        "arn:aws:iot:YOUR_REGION:YOUR_ACCOUNT_NUMBER:client/${iot:ClientId}"
      ]
    },
    {
      "Effect": "Allow",
      "Action": [
        "iot:Publish"
      ],
      "Resource": [
        "arn:aws:iot:YOUR_REGION:YOUR_ACCOUNT_NUMBER:topic/truck/freezer",
        "arn:aws:iot:YOUR_REGION:YOUR_ACCOUNT_NUMBER:topic/truck/analyze"
      ]
    }
  ]
}

    Comprobación de la comunicación

    Una vez que verificamos que la cosa tiene la política de AWS IoT correcta y los certificados y scripts están instalados en la instancia VSCode, el siguiente paso es ejecutar el script cliente en el dispositivo para comenzar la comunicación con el AWS IoT Core y comprobar en el cliente MQTT de la consola de AWS IoT que los mensajes se reciben.

    Inicio de la comunicación desde la instancia VSCode

    Para iniciar la comunicación desde el dispositivo haz lo siguiente:

    1. En la instancia VSCode abre un terminal en la carpeta scripts.

    2. Ejecuta el script start.sh (como ya se hizo en la práctica 1). Recuerda poner tu prefijo delante del nombre de la cosa.

    3. Si no hubo errores, el script se conectó al AWS IoT Core y está publicando mensajes en el tema truck/freezer.

    No pares el script

    Para que funcione el apartado siguiente el script tiene que estar ejecutándose en la instancia. No lo pares.

    Verificación de la comunicación desde el AWS IoT

    Para comprobar que la conexión funciona, vamos a verificar que el AWS IoT Core está recibiendo los mensajes enviados por el dispositivo (la instancia VSCode). Para ello haz lo siguiente:

    1. Accede a la consola del servicio AWS IoT.

    2. En el menú del panel lateral elige Cliente de prueba MQTT.

    3. En la pestaña Suscribirse a un tema, introduce el nombre del tema truck/freezer en el filtro de temas.

    4. Pulsa en Suscribirse. El nombre del tema aparecerá en la sección Subscripciones.

    En este punto, si la comunicación funciona, podrás ver los mensajes que se reciben en el tema.

    Los datos de cada mensaje muestran lo siguiente:

    • Cuánto tiempo lleva funcionando este dispositivo
    • La energía que va a la unidad de congelación
    • La temperatura en la parte trasera del camión
    • El estado de la puerta del congelador
    • Un identificador del dispositivo
    • Un número de secuencia del mensaje
    • Una marca temporal

    Nota

    La marca temporal está en formato de época. Para convertirla en un valor más sencillo, puedes usar el sitio web epochconverter.com.
