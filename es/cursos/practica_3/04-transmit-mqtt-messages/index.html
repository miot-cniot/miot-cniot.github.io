    4. Intercambio de mensajes MQTT

    En esta sección, comprobaremos la transmisión de mensajes MQTT hacia y desde el dispositivo IoT que configuramos previamente. Específicamente, haremos dos cosas:

    • Enviar mensajes MQTT desde el dispositivo a AWS IoT Core utilizando la configuración del objeto que creamos anteriormente.

    • Transmitir mensajes MQTT desde la consola de AWS IoT al dispositivo. Estos mensajes se almacenarán en el archivo especificado durante la configuración de AWS IoT Device Client.

    Envío de mensajes MQTT desde el dispositivo IoT

    Para comprobar el envío de mensajes desde el dispositivo, haz lo siguiente:

    1. En el menú de la izquierda de la consola del servicio AWS IoT Core, selecciona la opción: Probar → Cliente de prueba de MQTT.

    2. En el campo Filtro de temas, introduce # para suscribirte a todos los temas y poder ver los mensajes MQTT recibidos en cualquiera de ellos.

    3. Verifica que el mensaje "Hello World" se recibe en el tema /topic/workshop/dc/pub.

      Este mensaje se publica solo una vez y requiere que se haya creado un objeto y que el AWS IoT Device Client esté correctamente configurado en el dispositivo.

      Nota

      Si el mensaje no aparece, ejecuta el siguiente comando en una terminal de la instancia VSCode:

      $ sudo systemctl restart aws-iot-device-client

      Si las configuraciones realizadas en las secciones anteriores del tutorial se hicieron correctamente, se publicará un mensaje "Hello World" cada vez que se reinicie el servicio AWS IoT Device Client en el dispositivo.

      Mensaje recibida en el tema

    Envío de mensajes MQTT desde AWS IoT Core al dispositivo IoT

    Para comprobar el envío de mensajes al dispositivo, haz lo siguiente:

    1. Ejecuta el siguiente comando en una terminal de la instancia VSCode para monitorizar los cambios en el archivo de log de AWS IoT Device Client.

      $ sudo tail -F /var/log/aws-iot-device-client/aws-iot-device-client.log

      Nota

      Cuando quieras dejar de monitorizarlo, presiona Ctrl+C en la terminal.

    2. En el cliente de prueba MQTT de la consola de AWS IoT Core, publica un mensaje en el tema /topic/workshop/dc/sub.

      Publicación de un mensaje

    3. Verifica que en la terminal de la instancia VSCode donde estás monitorizando el log, aparece un mensaje similar a este:

      2026-09-10T17:01:09.739Z [DEBUG]{samples/PubSubFeature.cpp}: Message received on subscribe topic, size: 45 bytes

    4. Ejecuta el siguiente comando en una terminal de la instancia VSCode para comprobar el contenido de los mensajes MQTT recibidos en el dispositivo.

      $ sudo cat /home/ubuntu/workshop_dc/subfile.txt

      Este archivo es el que se configuró previamente en el tutorial para contener las cargas útiles (payload) JSON de los mensajes MQTT recibidos en el dispositivo. Deberías ver los mensajes que publicaste en el cliente MQTT de la consola de AWS IoT Core. Por ejemplo, algo como:

      {
    "message": "Lo saludamos desde la consola de AWS IoT"
}
