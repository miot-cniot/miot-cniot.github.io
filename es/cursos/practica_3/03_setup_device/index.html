    3. Set up the AWS IoT Device Client

    Para instalar el AWS IoT Device Client en la instancia VSCode, haz lo siguiente:

    1. Abre un terminal y crea un script de instalación ejecutando:

      $ cd /home/ubuntu/workshop_dc 
$ touch build_execute.sh
$ chmod ugo+x build_execute.sh

    2. Abre el script en un editor y copia en él el siguiente código:

      build_execute.sh
      #!/bin/bash

# Check if cmake is installed, if not, install it using snap with the classic confinement flag
if ! command -v cmake &> /dev/null; then
    sudo snap install cmake --classic
fi

# Set permissions for the workshop_dc directory
chmod 745 /home/ubuntu/workshop_dc/

# Navigate to the workshop_dc directory
cd /home/ubuntu/workshop_dc

# Clone the AWS IoT Device Client repository
git clone https://github.com/awslabs/aws-iot-device-client

# Navigate to the cloned repository
cd aws-iot-device-client

# Create and navigate to the build directory
mkdir build
cd build

# Generate the build files using cmake
cmake ../

    3. Guarda los cambios realizados en el script y ejecútalo en el terminal con el comando:

      $ ./build_execute.sh

    4. Si no hay errores en la salida del comando anterior, en el mismo terminal compila el AWS IoT Device Client ejecutando:

      $ cmake --build aws-iot-device-client/build --target aws-iot-device-client

      Si no hay errores, el comando debería finalizar con una salida como la siguiente:

      Salida de la compilación del Device Client.

    5. Para la configuración del Device Client vamos a necesitar especificar un archivo en el que recibir mensajes MQTT. Crea el archivo ejecutando en un terminal:

      $ touch subfile.txt
$ chmod 600 subfile.txt
