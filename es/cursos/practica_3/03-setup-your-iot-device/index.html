    3. Configuración del dispositivo IoT

    En esta sección, aprovisionaremos y conectaremos el dispositivo IoT. Para ello, haremos lo siguiente:

    • Crearemos un objeto en AWS IoT Core. Al crear el objeto, crearemos una identidad reconocida por AWS para el dispositivo IoT y le proporcionaremos una política para interactuar con los recursos de AWS.

    • Configuraremos el dispositivo, instalando el AWS IoT Device Client y usando la identidad que se creó para conectar el dispositivo de forma segura a AWS IoT.

    Crear el objeto para el dispositivo

    1. En el menú de la izquierda en la consola del servicio AWS IoT Core, elige la opción: Administrar → Todos los dispositivos → Objetos

    2. Pulsa en el botón Crear objetos, elige Crear un único objeto y pulsa en Siguiente.

    3. En el primer paso del asistente, nombra el objeto como deviceClientThing. Recuerda añadir tu prefijo delante.

    4. Pulsa en Siguiente para avanzar al siguiente paso del asistente.

      Propiedades del objeto

    5. Asegúrate de que está seleccionada la opción Generar automáticamente un certificado nuevo (la opción recomendada) y pulsa en Siguiente para avanzar al siguiente paso del asistente.

    6. En la sección de Políticas pulsa en Crear política para abrir la página de creación de políticas.

    7. En la página de creación de políticas, crea una política con la siguiente declaración de política:

      • Efecto: Permitir
      • Acción: *
      • Recurso: *

      Nómbrala como workshopDC con tu prefijo delante.

      Propiedades de la política

      Warning

      Esta política es demasiado permisiva y solo debe usarse para el tutorial. No es una política adecuada para un entorno de producción.

    8. Vuelve al asistente de creación de objetos, selecciona la política que acabas de crear y completa el proceso de creación del objeto pulsando en Crear un objeto.

      Política asociada al certificado

    9. Una vez completada la creación del objeto, se abrirá la ventana de descarga de certificados. Descarga el certificado y las claves privada y pública del dispositivo, y el certificado raíz de AWS.

      Warning

      Asegúrate de descargar los cuatro ficheros indicados en la captura, ya que esta es la única oportunidad que hay para hacerlo.

      Descarga de certificados

    Al completar este paso, hemos creado un objeto en AWS IoT Core, junto con una identidad reconocida por AWS (los certificados y claves), y hemos creado una política IoT para definir qué acciones puede realizar el objeto al interactuar con los recursos de AWS.

    Configuración del dispositivo IoT

    Vamos ahora a preparar el dispositivo IoT, configurando las credenciales e instalando y configurando el AWS IoT Device Client en la instancia VSCode.

    Configuración de las credenciales del dispositivo

    1. En una terminal de la instancia VSCode, ejecuta los siguientes comandos para crear un directorio en el que guardar las credenciales descargadas y configurar sus permisos.

      $ mkdir -p /home/ubuntu/workshop_dc/certs
$ chmod 700 /home/ubuntu/workshop_dc/certs

    2. Sube los cuatro ficheros del objeto descargados al directorio /home/ubuntu/workshop_dc/certs de la instancia VSCode.

      Opción para subir ficheros

      Nota

      En algunos sistemas operativos, el fichero .crt se descarga como .crt.txt, asegúrate de eliminar el .txt del nombre del fichero.

    3. En la terminal de la instancia VSCode, ejecuta los siguientes comandos para configurar los permisos de los ficheros que acabas de subir.

      $ chmod 600 /home/ubuntu/workshop_dc/certs/*-private.pem.key
$ chmod 644 /home/ubuntu/workshop_dc/certs/*-certificate.pem.crt
$ chmod 644 /home/ubuntu/workshop_dc/certs/AmazonRootCA1.pem

      Ficheros en el directorio certs con los permisos configurados

      Permisos

      Puedes ver aquí por qué estamos configurando estos permisos para los certificados.

    Instalación de AWS IoT Device Client

    Para instalar AWS IoT Device Client en la instancia VSCode haz lo siguiente:

    1. En una terminal de la instancia VSCode crea el script de instalación ejecutando:

      $ cd /home/ubuntu/workshop_dc
$ touch build_execute.sh
$ chmod ugo+x build_execute.sh

    2. Abre el script en un editor y copia en él el siguiente código:

      build_execute.sh
      #!/bin/bash

# Check if cmake is installed, if not, install it using snap with the classic confinement flag
if ! command -v cmake &> /dev/null; then
    sudo snap install cmake --classic
fi

# Set permissions for the workshop_dc directory
chmod 745 /home/ubuntu/workshop_dc/

# Navigate to the workshop_dc directory
cd /home/ubuntu/workshop_dc

# Clone the AWS IoT Device Client repository
git clone https://github.com/awslabs/aws-iot-device-client

# Navigate to the cloned repository
cd aws-iot-device-client

# Create and navigate to the build directory
mkdir build
cd build

# Generate the build files using cmake
cmake ../

    3. Guarda los cambios hechos al script y ejecútalo en la terminal con el comando:

      $ ./build_execute.sh

    4. Si no hay errores en la salida del comando anterior, en la misma terminal compila el AWS IoT Device Client ejecutando:

      $ cmake --build aws-iot-device-client/build --target aws-iot-device-client

      Si no hay errores, el comando debería finalizar con una salida como la siguiente:

      Salida de la compilación del Device Client.

    Configuración del AWS IoT Device Client

    En esta sección vamos a configurar AWS IoT Device Client. En concreto, activaremos las siguientes funciones del lado cliente:

    • Capacidad MQTT Pub/Sub

    • Trabajos remotos

    • Tunelización segura

    Nota

    A partir de aquí se asume que tenemos dos terminales abiertos simultáneamente en la instancia VSCode.

    En la primera terminal de la instancia VSCode, ejecuta el script de configuración de AWS IoT Device Client con los siguientes comandos:

    $ cd ~/workshop_dc/aws-iot-device-client/
$ sudo ./setup.sh

    Información do estado do servizo

    En este punto, se ha configurado e iniciado el AWS IoT Device Client como un servicio en el dispositivo IoT. El servicio se conectará automáticamente a AWS IoT.

    Nota

    Para ver si el servicio se inició correctamente (o si hay errores) se puede usar el comando:

    $ sudo systemctl status aws-iot-device-client

    Para hacer cualquier cambio en la configuración, es necesario detener AWS IoT Device Client usando el siguiente comando:

    $ sudo systemctl stop aws-iot-device-client

    Los cambios se hacen en el archivo de configuración (por defecto está en /etc/.aws-iot-device-client/aws-iot-device-client.conf) y se lanza de nuevo el servicio con el comando:

    $ sudo systemctl start aws-iot-device-client
