    9. Definindo as sombras de dispositivo

    Dispositivos, atributos e tópicos

    Esta sección resume os elementos IoT que vimos até agora e como se relacionan entre si no noso escenario da frota de camións de xeados.

    Dispositivos

    Os dispositivos son os compoñentes físicos que poden adoptar moitas formas.

    O camión de xeados está equipado cos seguintes dispositivos:

    • Sensores de temperatura
    • Sensores de porta
    • Actuadores
    • Sensores de voltaxe e batería
    • Marca temporal dos eventos

    Cada dispositivo IoT rexistrado ten un nome de cousa almacenado no rexistro do AWS IoT Core. Unha cousa é unha representación dun dispositivo específico ou entidade lóxica.

    Atributos, mensaxes, tópicos e o modelo de subscrición

    As cousas (e os dispositivos) teñen atributos. Os estados son os valores actuais destes atributos, as condicións e a disposición dunha cousa.

    • O conxelador está á temperatura desexada (cero graos).
    • A porta do conxelador está aberta.
    • O período Keep Alive está configurado en 60 segundos.
    • A mensaxe LWT está configurada en "Desconectado".

    Para controlar os dispositivos do camión de xeados, cómpre coñecer o estado actual (valor do atributo) do dispositivo e poder enviar un comando para cambiar o estado actual (cambiar o atributo), se é necesario. Cada dispositivo usa tópicos para comunicar os atributos e os valores. Isto faise a través do proceso de publicación-subscrición.

    Neste caso, un sensor de porta pode publicar o seu estado (aberto) no tópico sensor/door/truck_1/main_freezer. O estado actual da porta é "aberto".

    A aplicación dun usuario (subscrita a ese tópico) lería a información. A aplicación do usuario subscribiuse previamente ao tópico sensor/door/truck_1/main_freezer, polo que as publicacións nese tópico reenvíanse automaticamente.

    Introdución ás sombras de dispositivo

    Os dispositivos IoT ás veces desconéctanse. Hai que atopar formas de mitigar esta realidade. O camión podería estar nunha zona onde a conexión de rede non é fiábel ou é irregular. Nese caso, non poderías comunicarte co dispositivo. Na lección anterior, vimos como os mecanismos Keep Alive e LWT poden axudar con este problema. Pero AWS IoT Core ten máis cousas reservadas para nós.

    Aquí é onde entran as sombras de dispositivos (tamén chamadas sombras de cousas).

    Entón, que son as sombras de dispositivos e como axudan a mitigar cando os dispositivos se desconectan?

    En moitos xogos ou sitios web, pídenche que crees un avatar. No fondo, o avatar é de feito unha representación virtual de ti mesmo con información clave para o sitio web. Cando te desconectas, as persoas que acceden ao sitio web poden ver o teu avatar e a súainformación tal e como as definiches a última vez que estiveches en liña.

    Imaxina un usuario web que deixa un comentario ou che ofrece un pagamento. Aínda non o sabes, pero o teu avatar virtual actualízase, mantendo esta información pronta para ti cando te volvas conectar. Cando te volves conectar, o avatar virtual actualízache a información e ponte ao día do comentario ou do pagamento. Isto pode iniciar unha resposta pola túa banda ou requirir que realices unha acción baseada no pagamento enviado.

    Este escenario é similar ao concepto dunha sombra de dispositivo IoT. Unha sombra de dispositivo é unha representación e rexistro do estado dun dispositivo nun momento específico. Unha sombra é un documento JSON que se usa para almacenar e recuperar a última información recibida do estado dun dispositivo. O servizo de sombra de dispositivos actúa como intermediario (como o avatar anterior), permitindo que os dispositivos e as aplicacións recuperen e actualicen o estado dun dispositivo. As sombras viven na nube de AWS onde IoT Core accede a elas lendo e escribindo nelas. Isto ilústrase usando o noso camión de xeados e IoT Core máis adiante nesta sección.

    Mentres os dispositivos, as aplicacións e outros servizos na nube están conectados a AWS IoT, poden acceder e controlar o estado actual dun dispositivo a través das súas sombras. Por exemplo, unha aplicación pode solicitar un cambio no sensor de temperatura do noso camión de xeados actualizando unha sombra. AWS IoT publica unha mensaxe que indica o cambio no dispositivo. O dispositivo recibe esta mensaxe, actualiza o seu estado para que coincida e publica unha mensaxe co seu estado actualizado. O servizo de sombra de dispositivos reflicte este estado actualizado na sombra correspondente. A aplicación pode subscribirse á actualización da sombra ou pode consultar a sombra para coñecer o seu estado actual.

    Cando un dispositivo se desconecta, unha aplicación aínda pode comunicarse con AWS IoT e as sombras do dispositivo. Cando o dispositivo se volve conectar, recibe o estado actual das súas sombras para que poida actualizar o seu estado para que coincida co das súas sombras e, a continuación, publicar unha mensaxe co seu estado actualizado. Do mesmo xeito, cando unha aplicación se desconecta e o estado do dispositivo cambia mentres está desconectada, o dispositivo mantén a sombra actualizada para que a aplicación poida consultar as sombras para coñecer o seu estado actual cando se volve conectar.
