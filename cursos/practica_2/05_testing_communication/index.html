    5. Proba de conexión

    Comprobación da configuración

    Neste punto do titorial vamos verificar que dispoñemos dunha instancia VSCode e a súa cousa asociada correctamente configuradas para poder establecer unha conexión entre o dispositivo (a instancia VSCode) e o AWS IoT Core usando MQTT desde un cliente implementado mediante o SDK de Python de AWS.

    IMPORTANTE

    Esta sección asume que tanto a instancia VSCode como a súa cousa asociada xa se crearon e configuraron na práctica 1. Aquí só se verifica que se poida establecer conexión entre a instancia e o AWS IoT Core.

    Se non tes creadas a instancia e a súa cousa asociada, antes de continuar fai primeiro a práctica 1.

    Configuración da instancia VSCode

    Para verificar a configuración da instancia VSCode fai o seguinte:

    1. Accede á consola de xestión de AWS desde o AWS Academy Learner Lab.

    2. Accede á consola do servizo CloudFormation.

    3. Desde a aba Saídas da pila TruckSensor abre nun navegador a URL do VSCode instalado na instancia.

      Seña

      Se non lembras a seña de acceso, mira no documento que explica como lanzar instancias VSCode que tes dispoñíbel no Moovi.

    4. Asegúrate de que a instancia contén os certificados e scripts que se instalaron na práctica 1.

      Cartafois (certs, data e scripts) na instancia VSCode e o script start.sh aberto no editor.

    Configuración da política de AWS IoT

    Para revisar a política de AWS IoT asociada á cousa fai o seguinte:

    1. Accede á consola do servizo AWS IoT.

    2. Abre as propiedades da política truckSensor01-Policy (a que se creou na práctica 1).

    3. Asegúrate de que a versión activa da política coincida coa captura e o JSON proporcionados a continuación como exemplos.

      Propiedades da política truckSensor01-Policy coa versión correcta activada.

      JSON

      O JSON da política ten que coincidir co deste exemplo, substituíndo os valores de YOUR_REGION co teu código de rexión de AWS, como us-east-1, e YOUR_ACCOUNT_NUMBER co teu número de conta de AWS.

      {
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "iot:Connect"
      ],
      "Resource": [
        "arn:aws:iot:YOUR_REGION:YOUR_ACCOUNT_NUMBER:client/${iot:ClientId}"
      ]
    },
    {
      "Effect": "Allow",
      "Action": [
        "iot:Publish"
      ],
      "Resource": [
        "arn:aws:iot:YOUR_REGION:YOUR_ACCOUNT_NUMBER:topic/truck/freezer",
        "arn:aws:iot:YOUR_REGION:YOUR_ACCOUNT_NUMBER:topic/truck/analyze"
      ]
    }
  ]
}

    Comprobación da comunicación

    Unha vez que verificamos que a cousa ten a política de AWS IoT correcta e os certificados e scripts están instalados na instancia VSCode, o seguinte paso é executar o script cliente no dispositivo para comezar a comunicación co AWS IoT Core e comprobar no cliente MQTT da consola de AWS IoT que as mensaxes se reciben.

    Inicio da comunicación desde a instancia VSCode

    Para iniciar a comunicación desde o dispositivo fai o seguinte:

    1. Na instancia VSCode abre un terminal no cartafol scripts.

    2. Executa o script start.sh (como xa se fixo na práctica 1). Lembra poñer o teu prefixo diante do nome da cousa.

    3. Se non houbo erros, o script conectouse ao AWS IoT Core e está a publicar mensaxes no tópico truck/freezer.

      Instancia VSCode coa saída do terminal na que se executou o exemplo.

    Non pares o script

    Para que funcione o apartado seguinte o script ten que estar executándose na instancia. Non o pares.

    Verificación da comunicación desde o AWS IoT

    Para comprobar que a conexión funciona, vamos verificar que o AWS IoT Core está a recibir as mensaxes enviadas polo dispositivo (a instancia VSCode). Para elo fai o seguinte:

    1. Accede á consola do servizo AWS IoT.

    2. No menú do panel lateral escolle Cliente de proba (teste) MQTT.

    3. Na aba Subscribirse (assinar) a un tópico, introduce o nome do tópico truck/freezer no filtro de tópicos.

    4. Preme en Subscribirse (Inscrever-se). O nome do tópico aparecerá na sección Mensaxes recibidas.

      Páxina MQTT que solicita o nome dun tema ao que subscribirse.

      Neste punto, se a comunicación funciona, poderás ver as mensaxes que se reciben no tópico.

      Páxina do cliente de proba MQTT que mostra as mensaxes recibidas de forma regular.

      Os datos de cada mensaxe mostran o seguinte:

      • Canto tempo leva funcionando este dispositivo
      • A enerxía que vai á unidade de conxelación
      • A temperatura na parte traseira do camión
      • O estado da porta do conxelador
      • Un identificador do dispositivo
      • Un número de secuencia da mensaxe
      • Unha marca temporal

      Nota

      A marca temporal está en formato de época. Para convertela nun valor máis sinxelo, podes usar o sitio web epochconverter.com.
