    Recapitulación e Revisión

    Conectando dispositivos a AWS IoT Core

    Este curso cubriu os bloques de construción básicos de dispositivos e cousas e a información utilizada para rexistrar e organizar cousas dentro de AWS IoT Core. Isto incluíu unha visión xeral dos compoñentes clave de AWS IoT Core, incluíndo:

    • Pasarela de dispositivos – O punto de entrada seguro para que os dispositivos IoT se conecten a AWS IoT Core.

    • Mediador de mensaxes – Un axente de mensaxería que transmite de forma segura mensaxes cara e desde dispositivos e aplicacións IoT.

    • Seguridade e identidade – Os requisitos para a autenticación e autorización de dispositivos e clientes.

    • Rexistro de dispositivos – Unha base de datos buscable de dispositivos e os seus atributos, que axuda a xestionar cousas e organizar recursos.

    Asegurando dispositivos e autorizando accións

    Este curso centrouse en dúas áreas onde se aplica a seguridade nos sistemas IoT, segundo o proporcionado por:

    • Certificados e políticas de AWS IoT

    • Roles e políticas de IAM

    Certificados e políticas de AWS IoT

    Ao conectar dispositivos, AWS IoT Core crea as credenciais de seguridade necesarias para o dispositivo. Estas credenciais consisten no certificado X.509 que autentica o dispositivo e a política de AWS IoT, que se anexa ao certificado e autoriza o dispositivo.

    As políticas de AWS IoT definen que accións de AWS IoT Core poden ser realizadas por unha cousa. As políticas son documentos JSON que conteñen un conxunto de permisos. As políticas son entón anexadas ao dispositivo, usuario ou rol para darlles os permisos escritos na política.

    Roles e políticas de IAM

    Os roles de IAM traballan con políticas de IAM para conceder permisos a AWS IoT Core para acceder ao resto de AWS. As políticas de IAM conceden a unha identidade de IAM ou a un recurso de AWS permisos para acceder a un servizo ou realizar unha función con AWS.
