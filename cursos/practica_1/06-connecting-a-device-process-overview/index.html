    5. Conexión dun dispositivo: visión xeral do proceso

    A consola do AWS IoT Core fornece dúas opcións para a conexión de dispositivos: conexión dun único dispositivo ou conexión de varios ao mesmo tempo.

    A seguir, preséntase unha visión xeral paso a paso do proceso para provisionar un único dispositivo, tal e como se describe no escenario. Neste exemplo, usaremos o SDK de Python de AWS, pero podería usarse calqueira cliente MQTT moderno para conectarse ao AWS IoT Core.

    Conexión dun dispositivo

    Esta visión xeral ten dúas partes. Na primeira parte, comezaremos lanzando unha instancia VSCode que sirva de emulación dun dispositivo para o noso exemplo. Na segunda parte, crearemos unha cousa de AWS IoT, engadiremos atributos e descargaremos o kit de conexión para o dispositivo.

    Parte 1: Preparación da instancia VSCode

    Para lanzar a instancia VSCode que sirva de emulación dun dispositivo no noso exemplo, fai o seguinte:

    1. Accede á consola de AWS desde o AWS Academy Learner Lab.

    2. Lanza unha instancia VSCode seguindo as instrucións do documento que tes dispoñíbel no Moovi. Usa o nome TruckSensor e lembra engadirlle o teu prefixo.

    3. Abre un terminal na instancia que acabas de lanzar e executa o seguinte para descargar e descomprimir o ficheiro co preciso para emular o dispositivo:

      wget https://miot-cniot.github.io/stuff/TruckSensorFiles.zip && unzip TruckSensorFiles.zip

      Contidos do ficheiro

      Os contidos do ficheiro comprimido descargado son os seguintes:

      • Un cartafol de certificados que contén o certificado público da autoridade de certificación raíz de AWS, que é necesaria para conectarse ao AWS IoT Core
      • Un cartafol de datos cun ficheiro .csv usado para emular as medidas do sensor do camión
      • Un cartafol de scripts que contén o script utilizado para simular o sensor do camión

    4. Move os tres novos cartafois (certs, data, scripts) en TruckSensorFiles ao directorio /home/ubuntu. Unha vez movidos podes eliminar tanto o directorio TruckSensorFiles coma o ficheiro TruckSensorFiles.zip.

      Cartafois (certs, data e scripts) na instancia VSCode unha vez movidos.

    Parte 2: Crear unha cousa

    Na segunda parte desta visión xeral do proceso de conexión dun dipositivo, vamos a:

    • Crear un tipo de cousa e engadirlle atributos.

    • Crear a cousa que representa o sensor (o que está a ser emulado pola instancia VSCode que acabamos de lanzar na parte 1).

    Fai o seguinte para completar esta parte:

    1. Crear un tipo de cousa

    Comecemos creando un tipo de cousa. Deste xeito, ao crear unha cousa, poderás asociala co tipo de cousa.

    1. No menú da esquerda na consola do servizo AWS IoT Core, escolle a opción: Xestionar (Gerenciar) -> Todos os dispositivos -> Tipos de cousas

    2. Preme no botón Crear tipo de cousa (Criar tipo de item) para comezar a definir un tipo que represente o sensor do camión.

    1. Dalle o nome sensor_TempAndDoor á cousa. Lembra engadir o teu prefixo diante.

      Engadir unha descrición é opcional pero útil, xa que proporciona máis detalles sobre a información que captura o sensor.

    1. Na sección Configuracións adicionais, debaixo das propiedades do tipo de cousa, expande Atributos pesquisábeis.

    2. Preme en Adicionar atributo tres veces e insire os seguintes tres atributos: deviceID, powerRequired e trailerCapacity. Cada sensor, rexistrado como cousa, poderá establecer valores individuais para estes atributos.

      Propiedades do tipo de cousa.

    3. Preme en Crear tipo de cousa (Criar tipo de item) para crear o tipo de cousa.

    2. Crear a cousa que representa o sensor

    1. No menú da esquerda na consola do servizo AWS IoT Core, escolle a opción: Conectar -> Conectar un dispositivo.

      Móstrase a páxina do asistente Conectar un dispositivo, que axuda a crear os recursos da cousa, a política IoT e os recursos do certificado necesarios para conectar o dispositivo a AWS IoT para que poida publicar mensaxes de exemplo.

      O asistente segue os seguintes cinco pasos:

      1. Prepara o dispositivo.

      2. Rexistra e protexe o dispositivo.

      3. Escolle unha plataforma e un SDK.

      4. Descarga o kit de conexión.

      5. Executa o kit de conexión.

    2. Como o paso 1: Preparar o dispositivo, xa se fixo ao preparar a instancia VSCode na parte 1, preme no botón Próxima para avanzar ao segundo paso do asistente: Rexistre e protexa o seu dispositivo.

    3. Na páxina Rexistrar e protexer o teu dispositivo, nomea a cousa como truckSensor01. Lembra engadir o teu prefixo diante.

    4. En Configuracións adicionais expande Tipo de cousa.

    5. Na listaxe Tipo de cousa, escolle o tipo de cousa que acabamos de crear (sensor_TempAndDoor). Isto poboará automaticamente os atributos do tipo.

      Poderiamos engadir valores para o ID do dispositivo, o requisito de enerxía e a capacidade do remolque agora ou podemos facelo noutro momento. Deixaos sen valor polo de agora.

      Propiedades da cousa.

    6. Preme en Próxima para avanzar ao seguinte paso do asistente.

    7. O asistente axúdache a descargar un IoT Device SDK para o teu dispositivo. O SDK inclúe un programa de exemplo que publica e se subscribe a mensaxes MQTT. Escolle a plataforma (Linux) e o IoT Device SDK (Python) que coinciden coa instancia VSCode que se lanzou na etapa 1.

      Escolla da plataforma e o SDK.

    8. Preme en Próxima para avanzar ao seguinte paso do asistente.

    Na etapa de preparación, baixouse un ficheiro comprimido chamado TruckSensorFiles.zip, que contiña un certificado raíz e un conxunto de datos para simular lecturas de sensores. Agora vamos baixar o kit de conexión, que é outro ficheiro comprimido chamado connect_device_package.zip que contén o necesario para a seguranza do dispositivo: o certificado do dispositivo, a chave pública e a chave privada, ademais dun script para probar a conectividade co AWS IoT Core.

    1. Preme en Baixar o kit de conexión para baixar o kit ao teu computador. De momento non fagas nada con el, usarémolo máis adiante.

    Unha vez que baixes o kit de conexión, completa a creación da cousa avanzando polos pasos restantes do asistente.
