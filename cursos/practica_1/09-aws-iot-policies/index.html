    8. Políticas de AWS IoT

    As políticas de AWS IoT definen que accións de AWS IoT Core pode facer unha cousa. As políticas son documentos JSON que conteñen un conxunto de permisos. As políticas son entón xuntadas ao dispositivo, usuario ou rol para darlles os permisos configurados na política.

    Formato da política de AWS IoT

    Unha política de AWS IoT contén unha ou máis declaracións de política. Cada declaración de política contén as seguintes tres chaves:

    • Effect. Indica se a política permite ou denega o acceso.

    • Action. Inclúe unha listaxe de accións que a política permite ou denega.

    • Resource. Especifica unha listaxe de recursos aos que se aplican as accións. Se non se lista ningún recurso, a acción aplícase ao recurso ao que se xunta a política.

    Exemplo de documento JSON dunha política de AWS IoT que contén dúas declaracións de política para permitir as accións iot:Connect e iot:Publish para un único recurso cada unha.

    Accións de política

    AWS IoT Core tamén define un conxunto de accións de política que describen as operacións e os recursos aos que se lles pode conceder ou denegar acceso. Exemplos de accións inclúen as seguintes:

    • iot:Connect representa o permiso para conectarse ao axente de mensaxes.

    • iot:Publish representa o permiso para publicar nun tópico MQTT.

    • iot:Subscribe representa o permiso para suscribirse a un tópico MQTT ou filtro de tópico.

    • iot:Receive representa o permiso para recibir mensaxes nun tópico ao que se estexa suscrito.

    • iot:GetThingShadow representa o permiso para obter a sombra dun dispositivo.

    Para ver todas as accións de política dispoñibeis, consulta Accións de Política de AWS IoT Core.

    Accións iot:Connect e iot:Publish resaltadas nun exemplo de política de AWS IoT.

    Variábeis de política de cousas

    As variábeis de política de cousas facilitan a escritura de políticas de AWS IoT Core que conceden ou denegan permisos baseados en propiedades das cousas como nomes de cousas, tipos de cousas e valores de atributos de cousas. Poden usarse as variábeis de política de cousas para aplicar a mesma política para controlar moitos dispositivos de AWS IoT Core.

    Nos exemplos de políticas mostrados até agora, a variábel ${iot:Connection.Thing.ThingName} usouse no valor do Resource da declaración de política. Esta variábel resólvese no nome da cousa no rexistro de AWS IoT Core para o que se está avaliando a política.

    Para máis información, consulta Variábeis de Política de Cousas.
