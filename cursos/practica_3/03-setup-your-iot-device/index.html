    3. Configuración do dispositivo IoT

    Nesta sección, provisionaremos e conectaremos o dispositivo IoT. Para iso, faremos o seguinte:

    • Crearemos unha cousa no AWS IoT Core. Como parte disto, crearemos unha identidade recoñecida por AWS para o dispositivo IoT, e forneceremoslle unha política para interaxir cos recursos de AWS.

    • Configuraremos o dispositivo, instalando o AWS IoT Device Client e usando a identidade que se creou para conectar o dispositivo de forma segura a AWS IoT.

    Crear a cousa para o dispositivo

    1. No menú da esquerda na consola do servizo AWS IoT Core, escolle a opción: Xestionar → Todos os dispositivos → Cousas

    2. Preme no botón Crear cousas.

    3. Escolle Crear cousa única.

    4. No primeiro paso do asistente, dalle o nome deviceClientThing á cousa. Lembra engadir o teu prefixo diante.

    5. Preme en Próxima para avanzar ao seguinte paso do asistente.

    6. Asegúrate de que está escollida a opción xerar os certificados automaticamente (a opción recomendada) e preme en Próxima para avanzar ao seguinte paso do asistente.

    7. Na sección de Políticas preme en Crear política. Abrirase a páxina de creación de políticas.

    8. Na páxina de creación de políticas, crea unha política coa seguinte declaración de política:

      • Efecto: Allow
      • Acción: iot:*
      • Recurso: *

      Dalle o nome workshopDC co teu prefixo diante.

      Warning

      Esta política é demasiado permisiva e só debe usarse para o titorial. Non é unha política adecuada para un ambiente de produción.

    9. Volve ao asistente de creación de cousas, escolle a política que acabas de crear e completa o proceso de creación da cousa premendo en Crear.

    10. Unha vez completada a creación da cousa, abrirase a xanela de descarga de certificados. Descarga o certificado e chaves privada e pública do dispositivo, e o certificado raíz de AWS.

      Warning

      Asegúrate de descargar os catro ficheiros, xa que esta é a única oportunidade que hai para facelo.

    Ao completar este paso, creamos unha cousa no AWS IoT Core, xunto cunha identidade recoñecida por AWS (os certificados e chaves), e creamos unha política IoT para definir que accións ten permitido realizar a cousa ao interaxir cos recursos de AWS.

    Configuración do dispositivo IoT

    Vamos agora a preparar o dispositivo IoT, configurando as credenciais e instalando e configurando o AWS IoT Device Client na instancia VSCode.

    Configuración das credenciais do dispositivo

    1. Nun terminal da instancia VSCode, executa os seguintes comandos para crear un directorio onde gardar as credenciais descargadas e configurar os seus permisos.

      $ mkdir -p /home/ubuntu/workshop_dc/certs
$ chmod 700 /home/ubuntu/workshop_dc/certs

    2. Sube os catro ficheiros da cousa descargados ao cartafol /home/ubuntu/workshop_dc/certs da instancia VSCode.

      Nota

      Nalgúns sistemas operativos, o ficheiro .crt descárgase como .crt.txt, asegúrate de eliminar o .txt do nome do ficheiro.

    3. No terminal da instancia VSCode, executa os seguintes comandos para configurar os permisos dos ficheiros que acabas de subir.

      $ chmod 600 /home/ubuntu/workshop_dc/certs/*-private.pem.key
$ chmod 644 /home/ubuntu/workshop_dc/certs/*-certificate.pem.crt
$ chmod 644 /home/ubuntu/workshop_dc/certs/AmazonRootCA1.pem

      Permisos

      Podes ver aquí por que estamos a establecer estes permisos para os certificados.

    Instalación do AWS IoT Device Client

    Para instalar o AWS IoT Device Client na instancia VSCode fai o seguinte:

    1. Nun terminal da instancia VSCode crea o script de instalación executando:

      $ cd /home/ubuntu/workshop_dc
$ touch build_execute.sh
$ chmod ugo+x build_execute.sh

    2. Abre o script nun editor e copia nel o seguinte código:

      build_execute.sh
      #!/bin/bash

# Check if cmake is installed, if not, install it using snap with the classic confinement flag
if ! command -v cmake &> /dev/null; then
    sudo snap install cmake --classic
fi

# Set permissions for the workshop_dc directory
chmod 745 /home/ubuntu/workshop_dc/

# Navigate to the workshop_dc directory
cd /home/ubuntu/workshop_dc

# Clone the AWS IoT Device Client repository
git clone https://github.com/awslabs/aws-iot-device-client

# Navigate to the cloned repository
cd aws-iot-device-client

# Create and navigate to the build directory
mkdir build
cd build

# Generate the build files using cmake
cmake ../

    3. Grava os trocos feitos ao script e execútao no terminal co comando:

      $ ./build_execute.sh

    4. Se non hai erros na saída do comando anterior, no mesmo terminal compila o AWS IoT Device Client executando:

      $ cmake --build aws-iot-device-client/build --target aws-iot-device-client

      Se non hai erros o comando debería finalizar cunha saída como a seguinte:

      Saída da compilación do Device Client.

    5. Para a configuración do Device Client vamos necesitar especificar ficheiros nos que se gardaran as mensaxes MQTT entrantes e saintes. Crea os ficheiros executando nun terminal:

      • Ficheiro de suscrición

        $ touch /home/ubuntu/workshop_dc/subfile.txt
$ chmod 600 /home/ubuntu/workshop_dc/subfile.txt

      • Ficheiro de publicación

        $ touch /home/ubuntu/workshop_dc/pubfile.txt
$ chmod 600 /home/ubuntu/workshop_dc/pubfile.txt

    Configuración do AWS IoT Device Client

    Nesta sección vamos configurar o AWS IoT Device Client. En concreto, activaremos as seguintes funcións do lado cliente:

    • Capacidade MQTT Pub/Sub

    • Traballos remotos

    • Tunelamento seguro

    • Device defender

    Nota

    A partir de aquí asúmese que temos dous terminais abertos simultaneamente na instancia VSCode.

    No primeiro terminal da instancia VSCode, executa o script de configuración do AWS IoT Device Client cos seguintes comandos:

    $ cd ~/workshop_dc/aws-iot-device-client/
$ sudo ./setup.sh

    Os pasos de configuración son os seguintes:

    Paso 1.

    Do you want to interactively generate a configuration file for the AWS IoT Device Client? y/n
    • Insire y

    Paso 2.

    Specify AWS IoT endpoint to use:

    • No segundo terminal executa o seguinte comando para obter o endpoint:

      $ aws --region us-east-1 iot describe-endpoint --endpoint-type "iot:Data-ATS"

      Nota

      A resposta debería ser algo similar a: xxxxxxxxxxxxxx-ats.iot.us-east-1.amazonaws.com

      Copia a saída do comando anterior (sen as aspas) no primeiro terminal (no que se está a executar o script de configuración).

    Paso 3.

    Specify path to public PEM certificate:

    • No segundo terminal executa o seguinte comando para obter a ruta completa do ficheiro do certificado PEM público:

      $ ls /home/ubuntu/workshop_dc/certs/*.pem.crt

      Nota

      A ruta debería ser algo similar a: /home/ubuntu/workshop_dc/certs/xxxxxxxxxxxxxxxxxxxxxxxx-certificate.pem.crt

      Copia a saída do comando anterior no primeiro terminal.

    Paso 4.

    Specify path to private key:

    • No segundo terminal executa o seguinte comando para obter a ruta completa do ficheiro da chave privada:

      $ ls /home/ubuntu/workshop_dc/certs/*-private.pem.key

      Copia a saída do comando anterior no primeiro terminal.

    Paso 5.

    Specify path to ROOT CA certificate:

    Unha vez completados os pasos, iniciarase o servizo IoT Device Client. A saída indicará que o servizo está activo e cargado na memoria.

    Neste punto, configurouse e iniciouse o AWS IoT Device Client coma un servizo no dispositivo IoT. O servizo conectarase automaticamente ao AWS IoT.

    Nota

    Para ver se o servizo se iniciou correctamente (ou se hai erros) pode usarse o comando:

    $ sudo systemctl status aws-iot-device-client

    Para facer calquera cambio na configuración, é preciso deter o AWS IoT Device Client usando o seguinte comando:

    $ sudo systemctl stop aws-iot-device-client

    Os cambios fanse no ficheiro de configuración (por defecto está en /etc/.aws-iot-device-client/aws-iot-device-client.conf) e lanzase de novo o servizo co comando:

    $ sudo systemctl start aws-iot-device-client
