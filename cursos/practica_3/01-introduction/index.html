    1. Introdución

    Neste titorial instalaremos o AWS IoT Device Client nun dispositivo IoT virtual emulado mediante unha instancia EC2 co VS Code instalado. Isto permitirá que o dispositivo IoT virtual traballe con varias funcións de AWS IoT: conectar o dispositivo a internet, enviar e recibir mensaxes MQTT, operar ou actualizar o dispositivo de forma remota, supervisar a seguranza do dispositivo e acceder de forma síncrona ao dispositivo para a resolución de problemas.

    En concreto, neste titorial vamos a:

    • Crear unha cousa (unha identidade para o dispositivo en AWS IoT Core).

    • Configurar o AWS IoT Device Client no dispositivo IoT, e conectar de forma segura a cousa ao AWS IoT Core.

    • Intercambiar mensaxes MQTT entre o dispositivo IoT e o AWS IoT Core.

    • Definir e despregar unha operación remota Over-The-Air (OTA) no dispositivo IoT usando traballos remotos (Jobs), unha función do AWS IoT Device Management.

    • Configurar un heart-beat do dispositivo, supervisar métricas de saúde e seguranza do dispositivo usando AWS IoT Device Defender.

    • Configurar o acceso síncrono (SSH) ao dispositivo IoT co tunelamento seguro (Secure Tunneling), unha función do AWS IoT Device Management.

    AWS IoT Device Client

    O AWS IoT Device Client é un software modular, gratuíto e de código aberto escrito en C++ que pode compilarse e instalarse en dispositivos IoT baseados no Embedded Linux para acceder ás funcións do AWS IoT Core, AWS IoT Device Management e AWS IoT Device Defender.

    Serve como unha implementación de referencia para que os dispositivos IoT poidan traballar con servizos de AWS IoT, con boas prácticas operacionais integradas. Usalo é a forma máis sinxela de crear probas de concepto (PoC) para proxectos IoT. Ademais, dado que é de código aberto, pode modificarse para adaptalo a necesidades específicas de negocio, ou optimizalo cando se queira escalar dunha PoC a produción.

    Capacidades actuais

    O AWS IoT Device Client ten unha arquitectura modular que consta dun cliente base e un conxunto de funcións do lado do cliente que soportan o seguinte:

    • O cliente base xestiona a conectividade MQTT co AWS IoT Core: permite que o dispositivo IoT se conecte automaticamente e se suscriba aos tópicos MQTT relevantes para as funcións. Tamén fornece unha API de logging para os logs do dispositivo.

    • A función de traballos remotos (Jobs) do lado do cliente permite executar accións remotas no dispositivo cando se utiliza a función de traballos remotos (Jobs) do servizo AWS IoT Device Management. Fornece soporte para algunhas accións remotas por defecto, e extensibilidade para accións personalizadas. Poden usarse as accións personalizadas para controlar de forma remota o estado dos dispositivos IoT.

    • A función de tunelamento seguro (Secure Tunneling) do lado do cliente permite o acceso seguro e privilexiado ao dispositivo IoT cando se utiliza a función de tunelamento seguro (Secure Tunneling) do servizo AWS IoT Device Management.

    • A función Device Defender do lado do cliente permite recoller métricas estándar do lado do dispositivo cando se utiliza a función de detección baseada en regras (Rules Detect) do servizo AWS IoT Device Defender.

    • A función de aprovisionamento de frotas (Fleet Provisioning) do lado do cliente permite trocar credenciais provisionais por outras específicas para cada dispositivo cando se rexistra unha frota de dispositivos co AWS IoT Core. Esta función crea un certificado e unha chave privada específicos do dispositivo, e rexistra o dispositivo no AWS IoT Core.

    • A función de sombras con nome (Named Shadows) do lado do cliente permite controlar o dispositivo IoT utilizando AWS IoT Named Shadows. As sombras poden almacenar a información de estado do dispositivo e facela dispoñíbel para o dispositivo, os servizos de AWS IoT, as aplicacións e outros servizos de AWS, tanto se o dispositivo está en liña e conectado a AWS IoT coma se non o está.
