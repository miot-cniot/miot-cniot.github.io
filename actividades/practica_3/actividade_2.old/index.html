    Actividade 2

    DEFINICIÓN DUN MODELO DE DOCUMENTO DE TRABALLO PERSONALIZADO.

    Obxectivo

    O obxectivo desta actividade é definir un modelo de traballo personalizado.

    No curso creouse un traballo a partires dun modelo xestionado por AWS (sección 5.2) e un traballo personalizado a partires dun documento de traballo subido a S3 (sección 8.1). Nesta actividade vamos definir un modelo de documento de traballo personalizado que nos permitará crear traballos como o da sección 8.1 (echo dunha mensaxe no dispositivo IoT).

    Creación do modelo de documento de traballo personalizado

    Para crear o modelo fai o seguinte:

    1. No ambiente Cloud9 no que está instalado o AWS IoT Device Client crea un ficheiro JSON co modelo de traballo.
    $ pwd
/home/ubuntu/workshop_dc
$ nano customJobTemplate.json
$ cat customJobTemplate.json
{
  "version": "1.0",
  "steps": [
    {
      "action": {
        "name": "Greetings",
        "type": "runCommand",
        "runAsUser": "ubuntu",
        "input": {
          "command": "echo,Hello from Xoán C. Pardo\\, AWS IoT Device Client Workshop user on 2024."
        }
      }
    }
  ]
}

    Nota

    Na sección 8.1 do curso, usouse un documento de traballo co seguinte esquema:

    Para o modelo estamos a usar unha versión máis recente do esquema do documento de traballo. Podes ver aquí a documentación de ambos esquemas e aquí e aquí exemplos de documentos que usan a versión antiga e a máis recente respectivamente. Presta especial atención ao tipo de acción que estamos a usar e ao formato que se usa para o campo command.

    1. Sube o modelo ao bucket S3 que se usou no curso.

    Nomenclatura

    Usa o teu prefixo no nome do bucket.

    $ aws s3 cp customJobTemplate.json s3://xcpm2425-workshop-dc-bucket

    1. Na consola de AWS IoT escolle a opción Modelos de traballo dentro do menú Accións remotas.

    2. Coa aba Modelos personalizados escollida, crea un novo modelo de traballo escollendo Crear modelo de traballo e indicando as opcións seguintes:

      • Nome do modelo de traballo: greetingsTemplate. Lembra poñer o teu prefixo diante, p.ex. xcpm2425-greetingsTemplate.
      • Descrición: pon unha descrición para o modelo.
      • Documento de traballo: preme no botón Navegar no S3 e escolle o documento JSON que subiches a S3.

    Imaxe: configuración do modelo de documento de traballo.

    Creación dun traballo a partir do modelo

    1. No cliente MQTT da consola de AWS IoT subscríbete aos tópicos:

      • $aws/events/job/greetings/completed
      • $aws/events/jobExecution/greetings/succeeded

    2. Abre unha segunda consola AWS IoT para crear o traballo nunha xanela diferente á do cliente MQTT do paso 2. Nesta consola escolle a opción Traballos dentro do menú Accións remotas.

    3. Crea un novo traballo escollendo Crear traballo e indicando as opcións seguintes:

      • Tipo de traballo: escolle Crear traballo personalizado.
      • Nome do traballo: greetings.
      • Descrición: pon unha descrición para o traballo.
      • Cousas para executar este traballo: escolle deviceCLientThing.
      • Documento de trabalho: escolle Do modelo.
      • Tipo de modelo: escolle Modelos personalizados.
      • Modelo: escolle greetingsTemplate.
      • Tipo de execución do traballo: escolle Snapshot.

    Imaxe: configuración do traballo.

    Verificación da execución do traballo

    1. Comproba na consola do AWS IoT que o traballo se executou correctamente.

    Imaxe: execución correcta do traballo na consola IoT.

    1. Comproba tamén que o documento do traballo é o que definimos no modelo.

    Imaxe: documento do traballo.

    1. Comproba que se recibiron as mensaxes do traballo nos tópicos do cliente MQTT.

    Imaxe: mensaxes recibidas nos tópicos do cliente MQTT.

    1. E finalmente, comproba que apareza a mensaxe na saída de log do ambiente Cloud9.

    Imaxe: mensaxe no log do ambiente Cloud9.

    Xustificación da actividade

    Toma as seguintes capturas para a memoria de xustificación da práctica:

    1. Ambiente Cloud9 no que se vexa a saída da execución dos comandos seguintes:
    $ cat customJobTemplate.json
$ aws s3 ls s3://xcpm2425-workshop-dc-bucket

    1. Na consola IoT as propiedades do modelo de documento de traballo greetingsTemplate (con que se vexa o apartado de detalles é dabondo, os das configuracións non fan falla).

    2. Na consola IoT as propiedades do traballo greetings coa execución finalizada correctamente.

    3. Ambiente Cloud9 coa saída do traballo no ficheiro de log.

    Importante

    As capturas teñen que asemellarse ás que se tomaron no curso e nas prácticas anteriores. As capturas tomadas na consola AWS teñen que incluír o menú superior no que poida verse o nome de usuario da conta.
