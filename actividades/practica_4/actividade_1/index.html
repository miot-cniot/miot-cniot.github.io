    Actividade 1

    CONFIGURACIÓN DUN BRIDGE MQTT

    Obxectivo

    O obxectivo desta actividade é configurar un brige MQTT no dispositivo Greengrass para que actúe como gateway MQTT entre os dispositivos IoT e o AWS IoT.

    Hai dúas maneiras de despregar un broker MQTT no Greengrass:

    • Usando compoñentes Greengrass predefinidas. Con este método poden despregarse os brokers Mosquitto e EMQX.
    • Usando unha compoñente personalizada. Con este método pode despregarse calquera broker MQTT.

    No laboratorio da AWS Academy non podemos usar o primeiro dos métodos porque o rol IAM predefinido (LabRole) non ten permiso para asumir o rol de servizo do Greengrass, que é algo que as compoñentes MQTT predefinidas precisan para poder autenticar os dispositivos IoT con AWS IoT.

    Polo tanto, nesta actividade vamos usar o segundo dos métodos e despregaremos un broker MQTT Mosquitto usando unha compoñente personalizada.

    Importante

    Create the MQTT Bridge

    Para este subapartado hai instrucións adicionais a ter en conta para os pasos 2 e 5.

    Paso 2

    • Antes de executar o comando que consulta o endpoint, exporta a rexión na que estamos traballando executando no mesmo terminal no que vaias a executar o comando o seguinte: 

      export AWS_DEFAULT_REGION=us-east-1

    • No ficheiro bridge.conf, asegúrate de que no endpoint ATS a rexión que usas é us-east-1

    • No ficheiro cleanup.sh, cambia as liñas 7, 8 e 11 por estas:

      7.  CERTIFICATE_ID=$(awk -F '=' '{print $NF}' /etc/mosquitto/certs/cert-id.txt)
8.  REGION=us-east-1
11. CERTIFICATE_ARN=$(aws iot describe-certificate --certificate-id $CERTIFICATE_ID --region $REGION | jq -r '.certificateDescription.certificateArn')

    Paso 5

    Unha vez despregada a compoñente do bridge MQTT, comproba que se executaran os scripts definidos na receita da compoñente para os estados Install e Startup do seu ciclo de vida. Comproba tamén o contido do ficheiro /etc/mosquitto/mosquitto.conf e analiza os scripts para comprender como se creou a partir dos ficheiros de configuración que creaches previamente.

    Create the MQTT Bridge

    1. Instancia VSCode.

      Ten que mostrar na árbore de directorios a compoñente MqttBridge e nun terminal a execución dos comandos:

      $ sudo /greengrass/v2/bin/greengrass-cli component list | grep MqttBridge -A 3
$ sudo systemctl status mosquitto
$ ls -l /etc/mosquitto
$ ls -l /etc/mosquitto/certs/

    1. Instancia VSCode.

      Ten que mostrar na árbore de directorios as compoñentes BridgePublisher e BridgeSubscriber e nun terminal a execución dos comandos:

      $ sudo /greengrass/v2/bin/greengrass-cli component list | grep Bridge -A 3
$ sudo tail -f /greengrass/v2/logs/com.example.BridgeSubscriber.log
      Exemplo
