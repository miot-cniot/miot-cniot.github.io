    Actividade 3

    EXECUTAR UN EXEMPLO DA DEVICE SDK V2.

    Obxectivo

    O obxectivo desta actividade é probar un dos exemplos que veñen coa versión 2 do Device SDK e comparar os scripts cos que vimos na actividade 1.

    • O exemplo que vamos probar intercambia (publica e recibe) mensaxes co servizo AWS IoT Core de maneira segura usando MQTT5.

    Nota

    Podes ver aquí a documentación do exemplo.

    Pasos

    Fai o seguinte:

    1. Desde un terminal na instancia VSCode instala o Device SDK v2 para Python.

      • Clona o repositorio no teu directorio de traballo. 
        $ cd ~
$ git clone -b v1.24.0 \
    https://github.com/aws/aws-iot-device-sdk-python-v2.git \
    --recursive
      • Corrixe a versión no ficheiro __init__.py e instala o Device SDK 
        $ sed -i "s/__version__ = '1.0.0-dev'/__version__ = '1.24.0'/" \
    ./aws-iot-device-sdk-python-v2/awsiot/__init__.py
$ python3 -m pip install ./aws-iot-device-sdk-python-v2
...
Successfully built awsiotsdk
Installing collected packages: awscrt, awsiotsdk
    Successfully installed awscrt-0.27.4 awsiotsdk-1.24.0

    2. No directorio de scripts, crea un script start_v2.sh co contido seguinte para executar o exemplo.

      Nomenclatura

      Lembra usar o teu prefixo no nome da cousa.

      start_v2.sh
      #!/usr/bin/env bash

# stop script on error
set -e

# set the device name
device=<O_TEU_PREFIXO>-truckSensor01

# get the AWS IoT endpoint
aws iot describe-endpoint > /tmp/iotendpoint.json
iot_endpoint=$(jq -r ".endpointAddress" /tmp/iotendpoint.json)

# run MQTT5 pub/sub sample app
printf "\nRunning MQTT5 pub/sub sample application...\n"
python3 ~/aws-iot-device-sdk-python-v2/samples/mqtt5_pubsub.py \
  --endpoint $iot_endpoint --ca_file ~/certs/AmazonRootCA1.pem \
  --cert ~/certs/$device.cert.pem --key ~/certs/$device.private.key \
  --topic truck/pubsub --count 0

    3. Edita a política AWS IoT da cousa para permitir a subscrición ao tópico do exemplo e publicar e recibir mensaxes del.

      OLLO

      Lembra usar o ID da túa conta nos ARN (Amazon Resource Name) dos recursos.

      Política AWS IoT modificada.

    4. Executa o exemplo no directorio de scripts. 

      $ cd ~/scripts
$ chmod +x start_v2.sh
$ ./start_v2.sh

    5. No cliente MQTT da consola de AWS IoT subscríbete ao tópico truck/pubsub e comproba que se reciben as mensaxes enviadas desde a instancia VSCode.

    6. Desde o cliente MQTT da consola de AWS IoT publica algunhas mensaxes no tópico truck/pubsub e comproba que aparezan no terminal da instancia VSCode no que se estea a executar o script start_v2.

    7. Para o script premendo Ctrl+C no terminal da instancia VSCode.

    Importante

    Antes de continuar xa podes tomar as capturas que se piden para xustificar a actividade. Os seguintes pasos non é preciso xustificalos.

    1. Abre o script mqtt5_pubsub.py no directorio samples do Device SDK v2 e analiza o seu código. Compárao co da actividade 1. Presta atención en especial a:

      • Como se importan as compoñentes de MQTT5.
      • Como se crea un cliente MQTT5.
      • Como se abre e pecha unha conexión co cliente MQTT5.
      • Como se realiza unha subscrición a un tópico MQTT5 e como se anula.
      • Como se publican e reciben mensaxes co cliente MQTT5.

      Nota

      Consulta a documentación do SDK v2 para MQTT5 aquí e aquí.

    2. Este paso é opcional. O script pubsub.py no directorio samples do Device SDK v2 é unha implementación do mesmo exemplo que acabamos de ver pero usando MQTT311. Modifica o script start_v2.sh para executar este exemplo e comproba que funciona.

      Nota

      Podes consultar a documentación do SDK v2 para MQTT311 aquí e aquí.
